# Introduction à HTML

HTML (HyperText Markup Language) est le langage standard utilisé pour créer des pages web. Il permet de structurer le contenu d'une page à l'aide de balises. Les éléments HTML peuvent inclure des titres, des paragraphes, des images, des liens, des formulaires, et bien plus. C'est le point de départ pour toute création web, et il est souvent accompagné de CSS (Cascading Style Sheets) pour le style et de JavaScript pour les interactions.
